The class of a rescued error keeps its name

    class Slow < StandardError; end

    def class_of_a_rescue
      raise Slow, "orig"
    rescue => e
      e.class
    end

    k = class_of_a_rescue
    a = []
    60000.times { |i| a << ("s" + i.to_s) if i % 7 == 0 }
    p [k, k == Slow, a.size]
    begin
      raise k, "again"
    rescue Slow => z
      p [z.class, z.message]
    end

prints [Slow, true, 8572] and [Slow, "again"] in CRuby. It printed
[s30856, false, 8572] and then stopped at the raise: "exception
class/object expected (TypeError)".

An exception carries its class name as a bare C literal, which has no
marker byte, so sp_exc_class_name hands Ruby a marked copy. It made
that copy on the string heap, a new one each call. `e.class` puts the
copy in a Class value, a plain struct of an id and a name that no root
and no scan knows. Held in a local, a parameter or an instance variable
while Strings were made, the copy was collected and the class answered
with the String that took its place. `raise e.class, "m"` stores the
same copy as the new error's class name, and nothing marks that either:
the new error's class, its is_a? and the rescue arms that test it went
with whatever was allocated next.

sp_exc_class_name now keeps one marked copy for a name, off the string
heap, as a literal is, in a table keyed by the address of the literal
it was made from. Every holder of the Class value is right at once, no
generated C changes, and reading e.class no longer allocates: the
function runs 62 instructions a call with one class raised and 83
with 300, where the copy ran 124 to 131.

Two `e.class.to_s` are now the same String, as two `ArgumentError.to_s`
already are. CRuby answers a new String for each.

test/exception_class_name_kept.rb holds the class in a local, a
parameter and an instance variable and reads it back by to_s, name,
inspect, interpolation and ==, then returns it from a method and raises
it, and ends with twelve classes raised in turn. On master each of the
seven counts is wrong in a plain run and the test ends at the
TypeError. test/exception_class_raised_again.rb raises
the class of a rescued error at once, in a method, to a Thread and to a
Fiber. It is right on master in a plain run and wrong at
SPINEL_GC_STRESS=2, so it joins GC_STRESS_TESTS.
