The name of a rescued error's class is a fresh heap copy on each read
(sp_exc_class_name). sp_str_frozen_name, Module#name's cache, keys a
name by its address, on the premise that a name is a static string. A
copy the collector had freed gave its address to the next copy, of
another class's name, and the lookup answered the first.

Only a static name is now a key. Any other is interned by its bytes,
which is what the cache stored for it, and is held while the interned
copy is made: under SPINEL_GC_STRESS=2 that copy was made from freed
bytes. The cache no longer gains an entry a read.
