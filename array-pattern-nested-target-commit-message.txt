A target inside a nested pattern binds an assigned local to a value of any class

    t = "o"
    case [[:q, :r], 9]
    in [[_, *, t], _]
      p t                   # :r
    end

exited 139 with nothing printed, and `[[t, _], _]` there printed nil.
`n = 0` bound to the "b" of [["a", "b"], 9] printed 0, a Symbol local
printed :"" for a Float, and `r = "o"` bound by the rest of
`[[_, *r], _]` printed bytes of memory as a String.

What a nested pattern binds arrives boxed. pm_seed_locals_poly boxed
the locals of a Hash or find pattern that is a required element and
of a pattern under a Hash pattern's key, and no others: in a nested
Array pattern, in any pattern after the splat and in a Hash pattern
inside either, a local that an assignment also writes kept the
assignment's type, and the value was unboxed as that, whatever its
class. The first commit of this series walks those patterns too and
boxes only the target of a capture that names another class.

A bare target there boxes the local now: an element of a nested Array
pattern, a nested rest, the value of a Hash pattern under one. It
does so under the same list (pm_uses, pm_local_assigned): every
assignment to the local is a statement `x = literal`, and every other
use prints it, interpolates it or compares it with a literal. A local
with any other use is typed as it was and writes the same C. A
capture's target is decided by the capture, as it was. The first
name of an `a => x` is not bound by anything yet, at any depth, and
pm_seed_capture_value leaves its local typed.

The value may be of the class the local already held: `t = "o"`
taking the "s" of [[1, "s"], 9]. That program was right typed and is
right boxed, and pays a boxed comparison for a typed one: ten million
`t == "s"` take 0.097 s where they took 0.007.

Not cured here: a local with a use off the list (`p [t]` after the
pattern), which keeps its type and still exits 139.

Test: test/array_pattern_target_nested.rb (expected from CRuby
3.3.6); master prints seven wrong lines of it and exits 139. No other
program of the corpus changes its generated C.
