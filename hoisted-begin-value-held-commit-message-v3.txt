A begin or catch read as a value is held until its expression reads it

    def churn(n)
      i = 0
      x = nil
      while i < n
        x = ["c#{i}", "d#{i}"]
        i += 1
      end
      x
    end
    def tags_of(i)
      churn(200)
      ["t" + i.to_s, "x"]
    end

    rows = []
    300.times do |i|
      rows << (begin; tags_of(i); rescue; ["q"]; end) +
              (begin; tags_of(i); ensure; churn(10); end)
    end
    churn(2000)
    bad = 0
    rows.each_with_index do |r, i|
      bad += 1 unless r == ["t#{i}", "x", "t#{i}", "x"]
    end
    p bad
    p rows.find { |r| r.size != 4 || r[0][0] != "t" }

CRuby prints 0 and nil. A plain run printed 38 and
["c192", "d192", "t6", "x"]: the first Array of a row was freed, and
one that churn made took its place.

A begin read as a value runs ahead of its statement, into a temp the
expression then reads. The temp was rooted only when the begin had an
ensure body, for the time that body runs. But the value also waits in
it while whatever an operand after it puts ahead of the statement
runs: here the second begin, with the first one's Array in a temp
nothing else knows. A Struct's super with two such arguments, two
Strings added, an interpolation and a method called on the first
value went the same way. A plain call and an Array literal hold their
arguments themselves and were right. catch as a value has the same
temp and the same window.

Both temps are now rooted where they run ahead of the statement, for
every kind that holds a reference, the two Strings of a String Range
among them. A begin emitted as a statement expression is read where
it stands and keeps the root it had. So does a begin or a catch that
is its statement, all that a write to a local, an instance variable
or a global stores, or the one value a return hands back
(hoisted_value_is_stmt): in `x = begin ... end` the temp is read as
soon as it is written, a return copies it at once, and the generated
C is as it was.

Anywhere else the root is paid whether or not what reads the value
allocates first, and most programs that pay it were right: which
readers allocate before they read is not known where the temp is
made. It costs 9 to 40 instructions a value built with gcc and 16 to
25 with clang (callgrind): a loop that takes the size of one begin or
catch value 300,000 times and does nothing else runs 1.3% to 5.4%
more. The generated C of 71 of the 6,608 programs under test/,
benchmark/ and packages/*/test/ changes.

test/hoisted_begin_value_held.rb counts the wrong values for a
Struct's super with and without keywords, Strings and Arrays added,
an interpolation, a String Range, a receiver, and a catch on either
side. On master a plain run prints 30, 37, 1, 37, 0, 19, 3, 1 and 0
where CRuby prints nine zeros, and it aborts at SPINEL_GC_STRESS=2,
so it joins GC_STRESS_TESTS.
