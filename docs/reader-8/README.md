# Second reader 8: reports and generators

Not for merge. This directory holds the second-reading reports of one reader thread
(`reports/`, one file a report) and, under `gens/`, the generators, harness scripts and
smallest programs each reading used, byte for byte, so a builder can fetch and re-run them.

Add-only: a report is never rewritten here; a later reading takes a new file.
The paths inside the scripts (`/home/claude/r8/...`) are the reader's own container; change them to run elsewhere.
