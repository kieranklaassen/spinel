The first of two interpolated Strings is held while the second is made

    n = 1
    p "as#{n}b".include?("s#{n}")

prints true in CRuby and false under SPINEL_GC_STRESS=2, built with
gcc or clang; `s.sub("s#{n}", "q#{n}")` aborts there. The two Strings
are made where they stand, arguments of one C call, each held by
nothing: making the second can collect the first. Neither runs code,
so emit_operands_in_order saw nothing to order and declined.

An interpolated String with another made after it is now bound to a
rooted temp, in the order written; the last is still made in the
call. That is one root, eleven to fourteen instructions a call:
200,000 turns of `"a#{i % 10}b".include?("#{i % 7}")` go from
52,729,566 to 54,929,569, and of `s.sub("s#{i % 3}", "q#{i % 10}")`
from 143,143,367 to 145,976,030. A reader's value or an element read
beside the two runs nothing and stays in the call, unbound
(`o.name.sub("s#{n}", "q#{n}")`: 143,144,512 to 145,976,047).

Whether a String needs the root shows only in the arm's C, so the
call's text is read once it is rendered, and a call that reading
changes is emitted a second time and remembered:

- Where the statement that makes the last String runs another call
  beside it, that call's result is held by nothing either: `concat`
  with two folds its first argument in
  (`sp_str_concat(sp_str_concat(r, a), b)`), and `sub!` on a String
  an Array also holds copies its receiver. There the last String is
  bound too, a second root: `s.dup.concat("s#{i % 3}", "q#{i % 10}")`
  goes from 213,510,576 to 219,537,209, thirty a call.
- Where a String bound for the one after it is used up before that
  one is made, in a statement or a `||` arm of its own
  (`s.start_with?("q#{n}", "s#{n}")` is `f(s, a) || f(s, b)`;
  `between?`; a typed `push` of two), nothing is held across a make
  and the String is left where it stands: master's C, 66,076,358 on
  both for 200,000 turns of that `start_with?`.

A call with fewer than two interpolated Strings among its operands
does not pay; nor does one whose receiver is not of a kind in
ty_runs_no_code, nor one whose arm holds each String itself as it
makes it (`"a#{n}" + "b#{n}"`, `s.count("a#{n}", "b#{n}")`, a typed
unshift). Adjacent literals (`("ta" "g").equal?("t" "ag")`) fold to
a static String and make nothing: operand_is_interp_str no longer
answers for them. Each of those is master's C.

Of the 6379 programs tools/cident.sh compiles, two change their C:
the new test and test/frozen_literal_identity.rb
(`"#{n}".equal?("#{n}")`); both pass.

Not here, each as on master, under stress only: a String made in a
conditional's or `||` arm or in parentheses
(`s.sub(c ? "s#{n}" : "z", "q#{n}")`), a `&.` call, a String beside
a Symbol made from one (`"q#{n}".to_sym.to_s + "s#{n}"`), and a
String written ahead of the one call that runs beside it
(`(c ? a : b).sub("s#{n}", f(2))`, built with clang).
