A boxed Symbol's [] reads a Float, nil or appended String index

    g = { "s" => :stone, "f" => 1.5 }
    p g["s"][g["f"]]

printed "s"; CRuby prints "t". Symbol#[] is String#[] on the Symbol's
name. sp_poly_index_poly reads a Symbol receiver by an Integer, an
Integer Range and a Regexp; an index of any other kind that no earlier
arm takes fell to its last line, which reads offset 0. The arm a boxed
String now has for such an index (sp_poly_str_aref_other) takes a
Symbol's name too: a Float is cut, a Float Range slices, an appended
String is searched for, and nil, true or an Array is CRuby's TypeError.
