Real. Fixed in 59aabda7 on #7238, whose commit this line is in; this branch carries #7238's two commits underneath (cd3ddfe2, 59aabda7).

`subtree_owns_next`, the one-node form the Fiber arm asks, now looks in the receiver, the arguments and a `&blk` of a call with a block, and in the collection of a `for`; the block itself stays the inner iteration's. `Fiber.new { r = (next 7 if c; [1, 2]).each { |v| v }; r }.resume` answers 7 where it did not build, and `test/fiber_block_next_in_call_operand.rb` has the receiver, an argument and a `for` in a fiber, a thread and a generator, and a `&blk` in a fiber.

What this branch adds on top is the shape where the `next` is the whole of its parentheses, `r = ((next 7 if c); [1, 2]).map { |v| v + 1 }`. On master that built and answered [2, 3]: the expression emitter took the `next` as its value. 2e693ca0 here writes it as the statement it is, which is what brought it to this walk and to the C error. On 9248ea83 it answers 7, and [2, 3] when the `next` is not taken. `test/fiber_block_next_expression_in_call_operand.rb` (9248ea83) has it as a receiver in a fiber, a thread and a generator, and as an argument in a fiber, with a `next` of the call's own block beside it; it prints its `.expected` plain and under `SPINEL_GC_STRESS=1`.

One program of the kind does not pass, for another reason: with the seed written `(next 7 if c; [])` the resume that takes the `next` answers 7, and the other raises NoMethodError on nil. `p [1, 2].each_with_object((1; [])) { |v, a| a << v }` raises the same on master with no `next` in it; a seed of `[0]` answers [0, 1, 2].

The any-`next` form of the walk, which the emitters of blocks spliced in place ask (a yielded block, tap, Array.new with a block, `emit_fallback_block_value`), is left as it is on purpose: `emit_fallback_block_value` leaves the leading statements out of a `delete` block that has a `next`, so answering for it there too turns `h.delete(:z) { |k| puts "lead"; (next 5 if c; [k]).each { |v| p v }; 7 }` from a C error into a wrong answer (7, no "lead"). Those shapes answer on 9248ea83 as they do on master.
