Share facts are built from the methods a call reaches

    a = ["a", "b"]
    a.each.with_index { |s, i| p [s, i] }
    a.map.with_index { |s, i| p s + i.to_s }
    a.each.each_with_index { |s, i| p [s, i] }

did not build under --share-strings, and other programs were refused
or answered wrongly, where each was right before "sh_targets_in reads
cplan_targets; the scope-name index goes". The default build is not
affected.

The walk read every method, also one no call reaches. Codegen emits
no C for such a method and its locals are never given a type, and
since that change a call on a receiver with no type is one the walk
does not follow. So the `buf << x` of __enumw_each_slice in
builtins/enumerator.rb, spliced with the chained iterator and called
by nothing here, put an in-place change among the Strings of every
call the walk does not follow, and each String that met such a call
became a handle.

The walk now leaves out a method no call reaches, and sh_jumps the
value of a `break` or a `next` in one. Reachability goes by name and
is computed before the fixpoint and again after it, so a method that
a call the walk reads reaches is read whatever its mark says: a pass
writes `e.map { break }` as a call to __enumw_map in between.

test/share/share_strings_unreached_method.rb holds the lost kinds. It
is in test/share because `make share-strings-test` runs only the
tests there under the flag.
