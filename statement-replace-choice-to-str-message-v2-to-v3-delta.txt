OLD:
Eleven sources found take the root and were right, because the tree
does not show what the emitter did with the read: `k && t` with a
boolean k and `n ||= t`, where the String is boxed by its handle and
not copied; a begin block, alone or with a rescue or an else arm,
an if with no else and an elsif chain, each run into a rooted temp
ahead of the statement; `$g = t`, where the global holds the copy;
a boxed String where a class defines to_str; and an object whose
to_str answers a String it holds. The root is 12 to 17
instructions a statement with gcc and 14 to 20 with clang.

NEW:
Sources of three families take the root and were right, because the
tree does not show what the emitter did with the read. The String
is boxed by its handle and not copied: `k && t` with a boolean k,
`n ||= t`, `false || t`, `k ? t : 5`, a loop that hands it out by
`break`. The source is run into a rooted temp ahead of the
statement: a begin block, alone or with a rescue or an else arm, an
if with no else, an elsif chain, an in arm. The variable written
holds the copy: `$g = t`, `@x = t`. A write to t in place of the
read pays the same in a loop's `break` and in the forms run ahead.
So do a boxed String where a class defines to_str, and an object
whose to_str answers a String it holds. The root is 10 to 17
instructions a statement with gcc and 10 to 20 with clang.
