String#split with a limit measures the String and its separator by bytes

    p "x,a\0b".split(",", 2)     # ["x", "a"], CRuby ["x", "a\u0000b"]
    p "a\0b\0c".split("\0", 2)   # ["a"], CRuby ["a", "b\u0000c"]

sp_str_split_limit's arm for a positive limit read the String with
strlen and sought the separator with strstr, where the unlimited split
(sp_str_split_into) reads byte lengths and searches by bytes. A field
after a NUL was lost, and a separator that starts with a NUL was taken
for the empty one.

The arm reads byte lengths now. A one-byte separator is found by
memchr; a separator holding a NUL by sp_bytestr; any other still by
strstr, run again behind each NUL of the String, since such a
separator cannot lie across one.
