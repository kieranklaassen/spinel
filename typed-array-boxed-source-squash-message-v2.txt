An Array a call returns is held while its elements are boxed

`take(*floats(i))` fills the rest parameter with a new Array of boxed
values made from the Float Array, and `fmt % ints(i)` hands String#% one
made from the Integer Array. Both come from sp_typed_to_poly, which
allocates the new Array before it reads the old one and holds the old
one nowhere. A result no variable holds was collected by that allocation
and its elements were read out of a buffer already given back.

A source that something holds needs no root: a variable, a constant,
self, or an Array literal, which sits in a rooted temp
(typed_array_src_held). Those calls compile as before. Any other source
is boxed by sp_typed_to_poly_unheld, which holds it for the call.

sp_PolyArray_eq_typed held the source and compared against a boxed copy
that nothing held. An element's own == allocates, and at
SPINEL_GC_STRESS=2 the copy was collected under the comparison. The slot
that holds the source now holds the copy once it is made, and the copy
holds the Strings of a source nothing else holds, so a comparison keeps
its two roots.
