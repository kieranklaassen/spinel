A default left out of a call on a boxed receiver runs in its own arm

    class Symbol
      def note(k = [self]) = "n #{k.inspect}"
    end
    [:abc].each { |x| puts x.note }

printed "n [:note]". emit_poly_user_arm0 writes the defaults a
zero-argument call leaves out, and what a default hoists (an Array
literal's construction, a call's temp) went to the statement's prelude:
ahead of the statement the dispatch stands in, where the receiver's
temp is not assigned yet, and outside the switch, where a receiver of
any class ran it. So the default read a receiver that was not there (a
zero Symbol; a null object for `k = [@iv]`, a crash), a default that
runs something ran for every receiver, whatever its class, and where
the temp is declared inside the dispatch's own expression the C did not
build (`k = first` in Range).

The arm now takes what each default hoists by itself. Where that text
names the receiver's temp, or the default has an effect, it is written
inside the arm's case, in a block, and the value is handed to the call
through a temp declared ahead of the statement, where the default's own
was: the switch names a temp of its function as before, so pd_hoist
leaves it inline as before. A default that hoists nothing (`k = tick`)
or only builds (`k = [1, 2]`) keeps its place and its C.

No other test's generated C changes.
