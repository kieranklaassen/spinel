`total += v` into an Integer local holds what the operator answers

A local that starts as an Integer kept its Integer slot through a
compound assignment whose operand is a boxed value, and the operand
was converted into the slot. A Float lost its fraction and a Bignum
added nothing:

    Item = Struct.new(:name, :price)
    items = [Item.new("a", 3), Item.new("b", 2.5)]
    total = 0
    items.each { |i| total += i.price }
    p total                    # Spinel: 5, CRuby: 5.5

`total = total + i.price` prints 5.5: infer_write_types gives the
local the type of that sum, a box. The op-assign arm fell to `newt =
ct` for a boxed operand. Where the operator is one of + - * / % ** it
now boxes an Integer or a Bignum local, so the two spellings type the
local alike.

The cost: such a local is boxed also where the operand only ever
holds an Integer that fits. A loop adding a million elements of a
two-kind Array into `total` runs 61.7 million instructions under
callgrind where it ran 29.7 million; spelled `total = total + x` it
runs 63.7 million on master.

Left alone: a parameter, a global, an Array element and an attribute
(`c.total += x`) as the target, which have arms of their own; the bit
operators and the shifts, where the spelled form keeps the Integer
slot too; a nil operand, which raises TypeError as before.
