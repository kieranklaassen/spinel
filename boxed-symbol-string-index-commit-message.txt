Symbol#[] is String#[] on the Symbol's name. sp_poly_get_str answers
the substring for a String and for a shared String, and answered nil for
a Symbol with every other value that is no object. A Symbol now answers
as its name does. The test stands where the receiver is already known
to be no object, so a Hash's read does not meet it.
