=== of a String Range covers a boxed String

    h = {"k" => "ab", "n" => 5}
    r = ("aa".."az")
    p r === h["k"]
    p ["c", 5, "q", nil].grep("a".."m")

printed `false` and `[]`; CRuby prints `true` and `["c"]`.

`===` of a receiver that compares by value (a number, a String, a
boolean, a Symbol) with a boxed argument is written as sp_poly_eq of
the two. That arm leaves out an Integer Range and a Float Range, which
cover, by their families 5 and 6 of eq_family; a String Range is family
7 and was not left out, so `("aa".."az") === x` asked whether the Range
equals x. No String does.

The arm leaves 7 out as well, and emit_range_call answers: a plain
String is covered by its bytes and length, and so is the text of a
shared String handle (an appended String). grep and grep_v with a
String Range, and a block that asks `===` of each element, are right
with it.

A value that holds no String is not covered. That includes an object
with a <=> of its own, which CRuby asks and this call does not, before
or after. One answer changes beside the String's: a boxed String Range
equal to the receiver was `true` and is `false`, as in CRuby, where a
Range is no member of itself.

Master's C stays where cover? of the Range keeps it (the commit
beneath): in a program that has, or may have, a ===, a <=>, an == or a
succ of its own, in any class (this call does not ask them, before or
after), and in one where that commit does not say what a box tagged as
a handle holds: it stores the String of a method call the scan does
not follow.

It stays as well in a program that may have an `each` of its own
(an_prog_never_gives, the walk the commit beneath asks: a def of that
name anywhere, the Symbol :each, or a site where a method is named,
made, mixed in or loaded by something the text does not spell; a
package's Ruby is the program's text to it, so a program that requires
set or csv stays too). grep and grep_v ask this `===` of each element,
and over an Array they walk as the builtin does where CRuby walks by
the `each` the program gave it:

    class Array
      def each
        self
      end
    end
    p ["c", 5, "q", nil].grep("a".."m")

prints `[]` in CRuby and on master, which finds no String for another
reason, and would print `["c"]` with the arm.

Cost: none on a program master answered right. The Range is no longer
boxed for the question: 300,000 turns of `n += 1 if r === x` run
237 and 208 instructions a turn fewer for an Integer x, and 86 and 56
fewer for a String outside the Range (callgrind, gcc 13.3 and clang
18.1).

Not here: case/when with a boxed subject (the next commit). `K === x`
for a constant K that holds a String Range answers false. all?, any?
and none? of a String Array with a String Range answer as if no element
matched.
