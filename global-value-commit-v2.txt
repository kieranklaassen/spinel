The value of a String index assignment on a global is its right-hand side

`$g = +"abc"; r = ($g[0] = "x")` raised NoMethodError, "undefined
method '[]=' for an instance of String", with an Integer, a (start,
length), a Range and a String key alike, and so did the assignment as
a method's last expression or as an argument. As a statement it
stored. The value arm in emit_call_operator_arms takes a local and an
ivar by node type; a global, a class variable and a constant went on
to the NoMethodError gate.

The arm now takes those three where it can prove its answer
(str_aset_value_slot_recv): the right-hand side is a String that
cannot be nil, and every index is a literal, or a local variable
beside a value that runs no code. The statement runs and the
expression answers the right-hand side, evaluated once, as it does
for a local.

A String that cannot be nil is a literal; an interpolation; `to_s` on
a String or a number, which answers "" for nil; or `dup`, `+` and `*`
by an Integer literal where each String operand is one of these
itself. A `&.` call is not one, and neither is a method name the
program defines: a reopened String can make it answer nil.

A global can hold nil where its type is String. Whether it does is
read ahead of the value, and NoMethodError, "undefined method '[]='
for nil", is raised after the value ran, as the gate raised it.

Every other shape keeps the gate and its NoMethodError: a value out of
a variable or a method, and `dup`, `+` or `*` on one (a String
variable can hold nil, `s.dup` is then nil, and the statement takes a
nil value for an empty String), an Integer value, an index that runs
code, a local index beside a value that runs code.

Under SPINEL_GC_STRESS=2 the Integer index stops with "the mark
reached a freed heap string" on a global as it does on a local, as a
statement and with its value taken, before this commit and after it:
that is the Integer arm's own rooting fault, which "String#[]= with an
Integer index keeps its pieces rooted" closes. The test here is right
at levels 0 and 1 by itself, and at level 2 above that commit.
