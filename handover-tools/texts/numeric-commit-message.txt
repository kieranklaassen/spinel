A boxed number is not an instance_of? Numeric

    [1, 1.5].each { |v| p v.instance_of?(Numeric) }

printed true twice; CRuby prints false: instance_of? asks for the
object's own class, and no number's class is Numeric. A typed receiver
was right. emit_poly_isa_test's Numeric arm listed every numeric tag
whatever `exact` said, so the boxed test answered as is_a? does, for an
Integer, a Float, a Bignum, a Rational and a Complex.

The arm now answers false for the exact form. is_a?, kind_of? and
`Numeric === v` are untouched.
