A default a spread does not reach is held where the call can free it

    def two(x = "a" * 2, y = "c" * 2) = [x, y]
    xs = []
    p two(*xs)                      # ["aa", "cc"]

aborts under SPINEL_GC_STRESS=2 ("the mark reached a freed slot") with
gcc and clang. With no stress setting, of 300,000 such calls 2 answer
wrong, and 2 of the results kept from every 7th read back wrong, with
both compilers.

A parameter read out of a spread (a splat's element, the gathered
positionals, a `**`'s key) is written where the argument stands, with
its default as the other branch:
`sp_two((0 < len ? _t2->data[0] : sp_box_str(sp_str_repeat("a", 2))),
(1 < len ? _t2->data[1] : sp_box_str(sp_str_repeat("c", 2))))`.
A default that allocates is then fresh inside the call's parentheses,
where nothing roots it: the other default's allocation collects it, in
`Img.new(*xs)` the object's own allocation does, and in
`def later(x = "a" * 2) = -> { x }` the cell of the captured parameter,
which the callee allocates before it stores x.

"A Range or Rational read into a boxed parameter is held for the call"
records the slots whose value is built where it stands and holds them
where the list, as written, leaves such a value exposed
(arg_built_exposed). A spread slot whose default is fresh now joins
that record (spread_slot_fresh), so it is assigned to a rooted temp
where it stands and nothing runs earlier than it did.

Fresh is asked of the node and of the text. The node: the default can
allocate and what it leaves is no scalar (`1 + 1` has nothing to
hold), or it is kept by value and boxed for a boxed parameter
(`x = (1..3)`). The text: a Hash or an Array literal stands there as a
temp the prelude built and rooted, and is held already. One fresh
default into a method that roots its parameters first is written as it
was, and so is a `super(*a)` into an initialize: the object exists.

A program that defines a finalizer keeps its C: the temp holds the
default until the calling function returns, and a finalizer on it would
run late.
